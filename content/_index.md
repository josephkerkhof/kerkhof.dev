## Dev Philosophy

I value proven, battle-tested tools with strong communities and reliable stability.

My production work involves REST APIs, MySQL, Redis, AWS, Docker, observability, and CI/CD. I have experience using DDD,
CQRS, TDD, and load testing.

I, like most software engineers these days, make heavy use of AI tools to my benefit, but engineering discipline is
still critically important. I follow Mitchell Hashimoto's
["whiteboard defense"](https://x.com/mitchellh/status/2100249348345057389) process.

I'm well versed in customizing my AI tools to help make triaging issues faster and automate repetitive tasks.

I read the code.

I have worked remotely since 2019. Thoughtful documentation, comprehensive PR reviews, clear asynchronous communication,
and practical guidance for other engineers are part of how I deliver software, not separate activities.
